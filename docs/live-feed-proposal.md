# Prepare Downwind for a live feed

## What runs today

On `main` at `7af1118`, the Python pipeline builds a 48-hour outlook from the previous UTC day's detections. The web app reads three committed September 2026 snapshots. The landing story explicitly selects 20 September and assumes that day's ranked fires are present. [Replay build](https://github.com/TheIntrinsicInvestor/downwind/blob/7af11185192e41c84aa2e7b3b01cbf9cf49d77d7/pipeline/dw/build.py#L39), [replay index](https://github.com/TheIntrinsicInvestor/downwind/blob/7af11185192e41c84aa2e7b3b01cbf9cf49d77d7/web/public/replay/index.json#L1), [landing page](https://github.com/TheIntrinsicInvestor/downwind/blob/7af11185192e41c84aa2e7b3b01cbf9cf49d77d7/web/app/(map)/page.tsx#L27).
